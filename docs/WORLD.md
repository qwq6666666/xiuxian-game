# 世界觀設定

> 本文件是寫作用的背景資料，不是系統規格。這裡的設定只用來讓事件、日誌、物品說明、殘卷彼此對得上；唯一對應到玩法的是殘卷收藏（GDD 第 18 節，M6）。
> GDD 第 15 節列為「不做」的東西（宗門、師徒、地圖、NPC 關係、戰鬥、元嬰以上境界）在這裡只能當歷史、遠景與傳聞出現，不能變成可操作的系統。
> 第 1–11 節是寫作指南，第 12–17 節是世界本身：三界、位階、歷史、勢力、地方、殘卷。
> 玩家看得到的文字仍然照 GDD 第 17 節的語氣寫。

## 1. 一句話

這是一個「人人知道能修仙，卻幾乎沒人修成」的世界。天道公平，只是不講情面；輪迴是常態，不是恩賜。

## 2. 天地如何運作

### 2.1 靈氣

- 靈氣遍佈天地，像潮水，有漲有落，山川之間濃淡不一。凡人日日呼吸它，卻無從取用。
- 能把靈氣納入丹田的人，叫修行者。修行者與凡人的差別只在「能不能」，不在「配不配」。
- 靈氣不挑人品。善人與惡人吐納起來一樣順，這是天道最常被抱怨的地方。

### 2.2 壽元

- 凡人壽數約八十，練氣約一百二十，築基約兩百，金丹約五百。每上一階，壽元就長一截。
- 因此修仙界的根本動機不是長生，是**多活一陣**。「再撐一個境界」是所有人共同的口頭禪。
- 壽元用盡，神魂離體，這是天道的規矩，沒有例外，也沒有人喊冤得成。

### 2.3 輪迴與道韻

- 人死之後，神魂入輪迴，抹去前世的記憶與肉身，只留下一點無從言說的**道韻**。
- 道韻是修行時留在神魂裡的痕跡，修得越深，留得越多；首次踏上某一境界時留得格外深。
- 道韻不是記憶。轉世的人不記得前世的名字，只是吐納起來比別人順一點，說不出為什麼。
- 道韻能「購買」天賦，是因為神魂在輪迴關口會被重新塑形，留下的痕跡決定它長成什麼樣子。這是修仙界的常識，沒人覺得需要解釋。
- 輪迴自古就有，但道韻得以留存並非自古如此。它的來歷見第 14.3 節，今世無人知曉。
- 世人對輪迴的態度各異：有人視為退路，有人視為債務，有人乾脆當作每世都得重新開始的麻煩事。

### 2.4 「一念」

- 世上流傳一個說法：輪迴轉得再久，終歸起於一念。修行者管這個念叫「道心」。
- 這是本作名稱《一念輪迴》的出處，也是輪迴天賦「道心」的來歷。不必明說，只在偶爾的詞句裡露一下。

## 3. 境界在這個世界裡的樣子

| 境界 | 世人眼中的樣子 | 寫作時的語感 |
|---|---|---|
| 凡人 | 日出而作的人，偶爾聽說某處有人「引氣入體」 | 平實、柴米油鹽 |
| 練氣 | 剛上路的修行者。人數不少，成就有限，多半耗盡壽元也到不了築基 | 認真但吃力，常有笑點 |
| 築基 | 真正的修行者的起點。壽元翻倍，面貌一新，一生從此不同 | 鄭重、少吐槽 |
| 金丹 | 一方高人，百年難得一見，也是今世人間的頂點。本作到此通關 | 肅穆，點到為止 |

- **瓶頸**不是玄學，是修行者最熟悉的老朋友：修為滿了，關隘不動。悟性與丹藥只能加幾分把握，從來沒有保證。
- **築基丹**是練氣修行者最想要的東西，也是最容易被人拿來說嘴的東西。
- 突破失敗的人不會被嘲笑，大家都經歷過，只是不愛提。

## 4. 靈根與出身（寫作用的背景）

### 4.1 靈根

| 靈根 | 世人的說法 |
|---|---|
| 雜靈根 | 靈氣進得去，出不來，修行像往漏水的缸裡倒水。人數最多 |
| 三靈根 | 中庸之資。多數修行者是這一種，也最不容易被記住 |
| 雙靈根 | 少見，同輩裡會被多看一眼 |
| 天靈根 | 萬中無一。據說連靈氣都對他們客氣 |

- 靈根只決定修煉快慢，不決定人品、結局或價值。事件文字不要暗示「靈根差的人活該」。

### 4.2 出身

| 出身 | 背景氣味 | 可用的細節 |
|---|---|---|
| 農戶 | 靠天吃飯，講究實在 | 田埂、節氣、收成、鄰里 |
| 商賈 | 凡事先問價錢 | 算盤、帳本、行情、人情債 |
| 修仙世家 | 祖上有人修過，家底還在 | 殘卷、舊規矩、家訓、沒落的體面 |
| 孤兒 | 無牽無掛，也無靠 | 破廟、百家飯、早熟、運氣出奇地好 |

## 5. 世人如何生活

用來讓事件文字有「地方感」，全部是背景，不開地圖。

### 5.1 凡俗

- **村落**：山腳下的小村，有老人、孩子、田地，偶爾有人說起山裡的傳聞。
- **坊市**：修行者與凡人交易的地方，賣丹藥、符紙、舊法器，也賣沒人敢保證的消息。《坊市》是遊戲裡唯一的固定場所。
- **山野**：修行者的日常活動範圍。荒廢的洞府、斷碑、野獸、迷路的人，都從這裡來。

### 5.2 修行界的行當

這些是「聽說過、遇見過」的人，不是可以建立關係的角色。

- **散修**：沒有門派、獨自修行的人，數量最多，也最常出現在你的故事裡。
- **丹師**：煉丹的人。你只在買丹藥或遇到怪人時碰到，不會學煉丹。
- **老者與前輩**：偶爾點撥一句，真假難辨。是事件裡的「機緣」，不是師父。
- **劍修**：偶爾御劍過頂，與你無關，但足夠讓你羨慕一整天。
- **宗門**：只存在於傳聞：「聽說某山某宗又開山門了。」你沒資格去，也不會去。需要指名時用第 15 節的太衡宗。
- **魔頭、邪修**：同樣是傳聞與偶遇，不做正邪大戰。他們只是修行路上較危險的一種人。

### 5.3 日常安排的世界觀對應

| 安排 | 在這個世界裡是什麼 |
|---|---|
| 閉關修煉 | 關上門專心吐納，外界諸事少來打擾 |
| 外出歷練 | 見識風霜，或有機緣，亦有兇險；是唯一會遇上死亡風險的安排 |
| 採藥營生 | 入山採藥換靈石，修行稍緩；修仙者也得吃飯 |

## 6. 通貨與物品

- **靈石**：通用貨幣，修行者與凡人的坊市都收。數量永遠不夠。
- **聚氣丹**：入門丹藥，服了可以立刻補一筆修為。便宜，大家都吃，吃了也沒人誇你。
- **築基丹**：衝擊築基時服用，添幾分把握。昂貴，也是許多人一輩子沒買到的東西。
- **延壽丹**：壽元上限延長十年，每世至多服三顆。藥效有其代價，修行者心裡有數。

## 7. 這個世界的幽默從哪來

GDD 第 17 節要的是冷面吐槽。這裡整理幾個可以反覆使用的「笑點來源」，目的是讓吐槽有根，不是亂笑：

1. **修行的現實**：腿麻了就是悟道，打坐三日只換來一個噴嚏。大事裡的小事。
2. **修仙界的客套與算計**：前輩「點撥」之後順口問你有沒有靈石；高人贈丹，附一張免責字條。
3. **時間的錯位**：一個動作拖了三年，人間已過了一世。
4. **丹藥與機緣的商品化**：什麼都有行情，連奇遇都有人拿來討價還價。
5. **輪迴的小麻煩**：每一世都重新開始，前世的準備全部歸零，只剩一點說不出的熟悉感。

**不拿來吐槽的東西**：死亡本身、突破成功、連鎖事件的結局、通關、玩家的選擇。吐槽對象永遠是處境與常理。

## 8. 稱呼與用字

- **主角**：敘述中稱「你」。姓名只在狀態列與死亡那一行出現。
- **姓名風格**：姓一字、名兩字，取自 `data/names.json`，清雅偏古，不用現代人名與網路梗。
- **時間**：寫「三十七歲秋」，不寫「第 444 個月」。月份只在介面數值裡出現。
- **數量**：用「一顆」「一卷」「一道」這類量詞，不寫阿拉伯數字。
- **台灣用語**：「地面」「軟體」之類的現代詞不要出現；需要現代感的比喻一律換成古代對應物（算盤、帳本、渡口、茶攤）。
- **避免**：「遊戲」「數值」「等級」「系統」「玩家」「存檔」等出戲詞，介面文字除外。

## 9. 輪迴天賦的世界觀說法

介面上的名字與一句話說明已寫在 `talents.json`，這裡補充它們在世界裡的意義，方便日後寫事件時呼應。

| 天賦 | 在世界裡的意思 |
|---|---|
| 宿慧 | 前世的吐納痕跡，今生順手一些 |
| 天眷 | 輪迴關口被塑形時，多了一次重來的機會 |
| 福緣 | 前世結下的善緣，今生被冥冥之中記著 |
| 遺澤 | 前世留下的一點家底，沒被孟婆之類的規矩收走 |
| 道心 | 一念不動，突破失敗時比旁人少折損 |

## 10. 可以寫進事件的「世界底層問題」

這些不是主線，只是偶爾可以在事件裡露一下，讓世界顯得有深度。**事件敘述永遠不給標準答案**；其中第一題作者心裡有答案（第 14.3 節），只經由殘卷分層揭露；其餘三題不給答案。作者同樣不回答的事另列於第 14.5 節。

- 輪迴究竟是天道的恩典，還是一筆慢慢還的帳？
- 有沒有人記得前世？（傳聞有，但只是傳聞。）
- 金丹之上是什麼？沒人說得清，連傳聞都不統一。
- 為什麼靈氣不挑人品？有人說這正是天道的公平，有人說這是天道的疏忽。

## 11. 事件寫作對照

寫新事件前，先對照下面這張表，避免和既有設定衝突。

| 要寫的內容 | 該用的設定 | 避免 |
|---|---|---|
| 遇到高人 | 老者、前輩、丹師，點撥一句即走 | 收徒、拜師、加入門派 |
| 遇到衝突 | 散修、魔頭偶遇，抉擇決定損益 | 戰鬥過程、打鬥數值 |
| 去某地 | 山野、洞府、坊市、荒村；需要地名時用第 16 節的四處 | 地圖、地名連線、路線選擇、寫到殘階 |
| 獲得機緣 | 丹藥、殘卷、傳聞、靈石 | 功法、神兵、煉丹煉器；替殘卷的內容下結論 |
| 輪迴的暗示 | 說不出的熟悉感、夢、舊景 | 明確的前世記憶與劇情 |
| 境界變化 | 壽元延長、同輩的目光、世人的態度 | 元嬰以上的描寫（名字可以出現在殘卷與傳聞裡，不寫其人其事） |
| 提到歷史 | 天梯、絕通、各家各執一詞 | 敘述者直接說出第 14.3 節的真相 |
| 提到另外兩界 | 傳說、忌諱、夢、文書上的隻字片語 | 前往上界或幽冥、與仙人或鬼差對話 |

## 12. 三界

天道之下分三界。三界的名目人人會背，三界的內情幾乎沒人見過。

| 界 | 住的是誰 | 管的是什麼 | 與人間的往來 | 今況 |
|---|---|---|---|---|
| 上界 | 飛升得位的列仙 | 仙位。位有定數，一位一人 | 昔日經天梯上下，人間按年供奉 | 絕通之後再無音訊 |
| 人間 | 凡人與修行者 | 管不了什麼 | — | 照舊過日子 |
| 幽冥 | 輪迴司上下 | 帳。每個神魂一頁，記在輪迴簿上 | 人死必經，活人不得入 | 照常辦公 |

- **天道不等於上界。** 天道是三界共守的規矩，不是誰；上界只是爬上去的人住的地方，列仙一樣在天道之下。所以「天道公平」和「上界不公」可以同時為真，這是整段歷史的關鍵。
- **幽冥只認帳，不認人。** 輪迴司公事公辦，不偏正邪，不收供奉。寫幽冥相關的文字時，語感是衙門文書，不是陰森鬼域。
- **人間怎麼看另外兩界**：上界是傳說，幽冥是忌諱。凡人拜天不拜仙，修行者提到輪迴多半一句帶過。
- 三界在遊戲裡都**不是可以前往的地方**。上界與幽冥只出現在殘卷、傳聞、夢和一生回顧的字句裡。

## 13. 位階

以下全是寫作用的排序。遊戲內可達的只有練氣、築基、金丹，其餘只當名字用。

### 13.1 修行九境

| 階 | 境界 | 小階 | 壽元 | 今世的狀況 |
|---|---|---|---|---|
| 下三境 | 練氣 | 一層至九層 | 約一百二十 | 人數最多，多半止步於此 |
| | 築基 | 初期、中期、後期 | 約兩百 | 一地的人物 |
| | 金丹 | 遊戲內不分期 | 約五百 | 今世人間的頂點，本作到此通關 |
| 中三境 | 元嬰 | — | 殘卷稱千歲上下 | 絕通之後人間不復見 |
| | 化神 | — | 殘卷各說各話 | 同上 |
| | 煉虛 | — | 不詳 | 同上 |
| 上三境 | 合體 | — | 不詳 | 只剩名字 |
| | 大乘 | — | 不詳 | 只剩名字 |
| | 渡劫 | — | 不詳 | 只剩名字 |

- 渡劫圓滿者登天梯飛升，入上界候仙位。這是通天紀的常態，今世無人見過。
- **金丹之上為何無路（作者設定）**：結嬰須借「天光」，天光是沿天梯降下的上界清氣。梯斷之後人間再無天光，金丹便成了一世所能及的頂點。世人只知道「金丹之後無路」，不知道原因。
- 今人背九境，後六個多半背不全，次序也常顛倒。這是可以反覆使用的笑點。
- 下三境的壽元與 `realms.json` 一致；改數值時兩邊一起改。

### 13.2 上界的位階

今人所知全出自守梯紀的文獻，真偽難辨。

| 位階 | 說明 |
|---|---|
| 上真 | 掌天門與仙籙的主事者，名號不傳 |
| 列仙 | 有仙位者。仙位有定數，滿了就是滿了 |
| 散仙 | 飛升而未得位者，在上界候缺 |

### 13.3 幽冥的位階

| 位階 | 職掌 |
|---|---|
| 冥君 | 不見於任何文書，只見批註末尾一個「可」字 |
| 判官 | 斷帳：一世修行折算成多少道韻，由判官核定 |
| 司吏 | 記簿：輪迴簿的抄錄與保管 |
| 鬼卒 | 引魂：把人從人間帶到輪迴司門口 |

- 輪迴天賦在世界裡的對應：玩家花道韻買天賦，等於判官照帳重塑神魂（見第 2.3 節、第 9 節）。

## 14. 歷史

### 14.1 三紀

| 紀元 | 俗稱 | 大勢 | 留下什麼 |
|---|---|---|---|
| 通天紀 | 上古 | 三界相通，天梯尚在，九境俱全 | 幾乎只剩名詞 |
| 守梯紀 | 中古 | 大宗把持天梯，登梯名額有價。終於「絕通」 | 宗誌、帳本、候梯人的手札、荒廢的洞府 |
| 無梯紀 | 今世 | 天梯已斷，人間止於金丹，輪迴始留道韻 | 你正活在這裡 |

- **紀年方式**：史事一律寫「絕通前若干年」「絕通後若干年」。絕通距今多久不寫，只說「不知幾千年」。
- **轉世不回到同一年。** 每一世都比上一世晚，隔多久不寫，敘述裡也不出現距今的確切年數。
- 「絕通」一詞取意於《尚書・呂刑》的「絕地天通」，只借其意，不引原文。

### 14.2 絕通：世上流傳的說法

同一件事，各家記的不一樣。玩家要靠比對殘卷自己拼。

| 立場 | 怎麼說 | 隱瞞或不知道的 |
|---|---|---|
| 太衡宗（正史） | 逆修□□強闖天門不得，遷怒毀梯；上界震怒，天人永隔；本宗奉天命鎮守殘階 | 登梯名額是它賣的；階上有不能讓人看見的東西 |
| 野渡（散修口傳） | 大宗把梯，一個名額要價一條靈脈；□□為天下人斷之 | 沒有人真的見過□□；不知道天門早已不開，也不知道幽冥的事 |
| 通濟行（帳本） | 不說故事，只有數字：供奉年年解送，回執年年沒有；名額價錢年年漲 | 帳上沒記的它一概不知，也不想知道 |
| 輪迴司（文書） | 某年簿冊添了一欄，事由「依約」 | 不解釋 |

- 那個人的名字在所有文獻裡都是空的，一律寫作「□□」。原因見下節。

### 14.3 真相

> 這一節只有作者知道。**不得在事件敘述、日誌、一生回顧裡直說**，只能經由殘卷一份一份露出來。

1. 守梯紀末年，上界仙位已滿。上界不再放人進天門，供奉卻照收。
2. 太衡宗等守梯大宗知情，名額照賣。登梯的人到不了，折在半途；因為沒有人回來，世人都以為他們成了仙。
3. 一位渡劫修士登梯到了天門。門不開，階上盡是前人的遺蛻。他走了下來，是史上唯一下梯的人。
4. 他以活人之身入幽冥（史上唯一的例外），與輪迴司立約：押上全部道行和自己的姓名，換輪迴簿上添一欄「道韻留存」。姓名繳銷之後，三界所有文書上他的名字一併成了空白。
5. 約成之後他斷了天梯。從此飛升無路，但修行所得不再一死成空，人人可以一世一世往上攢。輪迴成了新的梯子，只是很慢。
6. 他自己也入了輪迴，是第一個帶著道韻轉世的人。

- 這回答了第 10 節的第一個問題：輪迴留道韻既不是天道的恩典，也不是欠帳，是有人拿自己換來的。
- 也是本作名稱的出處：輪迴轉了幾千年，起於一個人在天門前的一念（第 2.4 節）。
- 靈氣不挑人品，道韻也不挑門戶。這是□□要的，也是太衡宗最不願人知道的。

### 14.4 揭露順序

| 階段 | 玩家拼得出什麼 | 來源 |
|---|---|---|
| 第一、二世 | 從前有天梯，後來斷了；兩種說法互相指責 | 一層殘卷 |
| 首次築基之後 | 兩邊都沒說全：供奉沒有回執，名額照賣，階上有不能說的事 | 二層殘卷 |
| 通關前後 | 天門早就不開了；□□下梯、入幽冥立約；道韻由此而來 | 三層殘卷 |

### 14.5 留白

以下三件事作者也不寫答案，永遠不回答：

- □□如今輪迴到第幾世，是誰。
- 上界現在是什麼光景，還有沒有人。
- 金丹之上，今世是否有人不借天光走通過。

第三件是日後擴充的伏筆：道韻積得夠深，神魂或能自生其光。第一版不做，也不在文字裡明說。

## 17. 殘卷

殘卷是玩家讀得到的「世界內文獻」，也是第 14.3 節真相唯一的出口。系統規格見 GDD 第 18 節，這裡只管內容。

### 17.1 定位

- 一份殘卷只說一方的話，而且只說一小段。真相靠玩家自己比對。
- 殘卷跨世保留。角色不記得，記得的是玩家；殘卷錄卷首有一句：「這些你都讀過，只是不記得了。」
- 殘卷不給任何數值好處。它的報酬是「知道」。

### 17.2 文體

殘卷不是敘述者的聲音，所以不必稱「你」，但 GDD 第 17 節其餘規則照用（不用現代語、不提數值用語）。各來源有各自的口氣：

| 來源 | 口氣 | 笑點從哪來 |
|---|---|---|
| 宗誌、起居注 | 端正的史筆，四字句多 | 冠冕堂皇到露出破綻 |
| 帳本 | 只有條目和數字 | 數字自己會說話；抄帳人懶得抄 |
| 手札、日記 | 第一人稱，瑣碎 | 大事旁邊的小抱怨 |
| 口訣 | 順口、押韻、誇大 | 吹過了頭 |
| 輪迴司文書 | 衙門公文 | 經辦人只在乎格式 |

## 18. 九渡洲

> 本節與第 19 節是 M7（天下圖）的設定。地圖是**只讀的示意圖**，只用來顯示「你在哪裡、天下是什麼樣子」，不增加任何玩法（見 GDD 第 19 節）。
> 第 16 節「不做地圖」的限制在此放寬為：可以畫，可以點開看簡介，但不能移動、不能前往、不連成路線，事件仍然只寫第 16 節的四處地名。

人間只有一塊大陸，世人稱為**九渡洲**。海外只有傳說，不畫。名稱出自洲上九處古渡口，渡口一帶由野渡一脈世代照看，渡頭集即是其中之一。

### 18.1 地形

- 北高南低，三條大水自西向東流入海：北有**玄水**，中有**平川**，南有**嶺江**。
- 極北是無人荒原，殘階立在荒原深處。
- 靈脈多沿山走，所以大宗與門派都坐落在山地；平原與水澤多是凡人的國度。

### 18.2 六處地域

| 地域 | 位置 | 誰說了算 | 靈氣 | 特色 |
|---|---|---|---|---|
| 極北荒原 | 最北 | 無人（太衡宗巡守） | 天脈所在，外圍稀薄 | 殘階。去過的人都說沒有 |
| 玄朔國 | 北方 | 玄朔國朝廷，北境實權在太衡宗 | 北境山地濃，南部尋常 | 青垣在其北境，垣下、渡頭集、青垣山都在這裡 |
| 西陵國 | 西方 | 西陵國朝廷 | 山地濃 | 多山多關，天樞宗與紫霄觀所在 |
| 平川國 | 中部 | 平川國朝廷 | 尋常 | 水路交會、人口最稠，通濟行總號所在 |
| 澤越國 | 東方 | 澤越國朝廷 | 水澤一帶偏濕，靈氣駁雜 | 河網密布，滄浪宗與聽潮門所在 |
| 南嶺諸部 | 南方 | 各部族自理 | 山林深處濃 | 瘴氣重，棲霞谷所在；後世部族聯盟成國 |

- **國是凡人的政權**，管稅、管兵、管田畝；**宗門管靈脈**，管修行者。兩者互不隸屬，只在邊界和稅賦上互相遷就。
- 垣下「名義上歸太衡宗」（第 16 節）的意思，就是玄朔國朝廷在北境鞭長莫及，賦稅由太衡宗代收，兩邊都不吭聲。
- 修行者不當國君，也不當官；有的修行者替朝廷看家護院，但那是雇傭，不是效忠。

- 太衡宗是**守梯紀三大宗中唯一還守著殘階的**。這也是它至今端著的原因。

- 野渡不是宗門，沒有山門，地圖上以九個渡口的小標記表示，不畫勢力範圍。

### 18.4 地圖上看得到的地點

除了第 16 節的四處（垣下、渡頭集、青垣山、殘階），再加各國都城的名字、八家宗門的山門、通濟行總號與九個渡口的標記。

- 都城只有名字，沒有簡介：**朔城**（玄朔）、**陵城**（西陵）、**平川府**（平川）、**越州**（澤越）、**嶺南**（南嶺，部族無都城，只標一個集散地）。
- 殘階在地圖上用灰色標出，簡介只有一句傳聞：「階上有東西。去過的人都說沒有。」不得多寫。
- 「你在這裡」永遠標在垣下。主角每一世都生在這裡（第 16 節），不隨歷練移動。

### 18.5 簡介的文風

點開地域、宗門、渡口時顯示的簡介一律不超過兩句，照 GDD 第 17 節：

- 地域簡介是方志口氣，冷淡、帶一點無奈。
- 宗門簡介是外人眼中的樣子，不是宗門自己的說法。
- 不寫戰爭過程、不寫人物、不寫劇情。

## 19. 年表

年表決定地圖在不同時間長什麼樣子。**一張年表，兩種變化**：一世之內隨年齡推進，跨世隨輪迴往前。

### 19.1 時間怎麼走

- 世界有一個隱藏的「世年」，**不顯示給玩家**。第 14.1 節仍然成立：絕通距今多久不寫，隔多少年也不寫，介面上只看得到變化的結果。
- 第一世出生時世年為零。每過一年，世年加一；一世結束時再加一段**空白**（四十到一百年之間，由世數決定，不抽亂數），下一世從那裡開始。
- 所以每一世看到的天下都和上一世不同，而同一世之內，隨主角年紀增長也會有一兩次變化。
- 年表只有一條，每個人看到的是同一個世界，沒有分支，也不受玩家選擇影響。

### 19.2 變化的種類

| 種類 | 說明 | 地圖上怎麼看 |
|---|---|---|
| 易手 | 某塊地域改歸另一國 | 地域換顏色 |
| 立國、亡國 | 新國成立或舊國消失 | 圖例多一項或少一項 |
| 改名 | 國名或宗門名更換 | 名稱變了 |
| 宗門興衰 | 宗門在「興盛、平穩、衰微、閉山、覆滅」之間轉換 | 標記的樣式變化 |
| 宗門升降 | 門派升為大宗，或大宗降為門派 | 標記大小變化 |
| 新立 | 新宗門出現 | 多一個標記 |

- **太衡宗**一直在，起落都是「山門開不開」。它是這片天下最穩的一家，也是最不肯說話的一家。
- **天樞宗與滄浪宗**走向覆滅是年表的暗線，兩者是守梯紀的遺老。玩家若把年表與殘卷對照，大約能感到某種事正在一點一點收場。這種感覺是設計的目的，不得直接說破。
- **通濟行**一路擴張，不論時局，和第 15.1 節「什麼都賣」一致。
- 年表上不出現任何人名。出現「某某開山門」「某某遷都」這一類句子即可。
- 年表上**不出現**元嬰以上的修行者、上界、幽冥、天梯，也不暗示□□。

### 19.4 世年與一世的對應

一世約一百到兩百年，加上空白，約十二到十四世共約兩千五百年。上表的長度據此估算：玩得再久，也不會走出年表的尾端。若年表被走完，地圖就停在最後一個狀態。

### 19.5 變化的提示

- 地圖本身是被動的，不主動彈出。
- 殘卷錄用「●」提示有新殘卷；地圖按鈕同樣用「●」提示「天下有新變化」，點開後清除。
- 日誌與一生回顧**不**寫天下大勢，避免和敘事語氣打架。

## 20. 待定

- 遊戲名稱：目前暫用《一念輪迴》，與第 14.3 節的設定相呼應。若更名，第 2.4 節與第 14.3 節要一併調整。
- 專有名詞皆為暫定，可以整批替換：太衡宗、通濟行、野渡、青垣、垣下、渡頭集、殘階、地乳芝、輪迴司、輪迴簿、通天紀、守梯紀、無梯紀；第 18、19 節新增的九渡洲、玄朔、西陵、平川、澤越、南嶺，以及天樞宗、滄浪宗、青岡派、紫霄觀、玉簫門、聽潮門、棲霞谷、聽雪庵。
- 九境沿用常見的名目（元嬰、化神、煉虛、合體、大乘、渡劫）。若想要自己的一套，只需改第 13.1 節，遊戲內只用得到前三個。
- 是否加入一兩位長壽的固定人物，讓玩家隔世重逢（上一世的年輕築基，這一世已是垂暮長老）。要動到跨世資料，先不做。
- 金丹之上的伏筆仍以少量為原則：不計殘卷，每二十個事件不超過一則。
