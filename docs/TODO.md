## M48 階段 0 盤點：修行主畫面（2026-10-07，Claude，開發伺服器 800 寬實測）

**已有**：場景 SVG（呼吸、靈氣上升、落葉、燈火、煙；突破光爆、運功光圈脈動）、修為條平滑（過渡長度隨流速）、日誌新條目淡入、靈石與修為浮字、狀態列升降閃框、彈窗淡入與上浮、收合區展開、遇怪血條與傷害飄字、天劫收縮光環、一生回顧慢轉場、地圖路線推進。全部有 `prefers-reduced-motion` 關閉。

**缺的動態**
1. 修為條本身已是連續平滑（過渡長度等於一個月，階段 1 實測更正：先前誤寫成「一跳一跳」）；缺的是「一個月的時間感」：1 個月 = 1 秒，沒有月內節拍或季節標示，也沒有「滿格待突破」的視覺狀態。
2. 日常安排卡片切換沒有過場，也沒有進行中的視覺（閉關與歷練看起來一樣靜止）。
3. 場景只隨年齡與境界換，不隨安排與事件反應（歷練時沒有外出感）。
4. 運功只有光圈脈動，沒有按壓回饋；連續點擊（×10）沒有累積感。
5. 事件彈窗的選項沒有進場延遲與按壓回饋；結果出來沒有「選擇後」的轉場。
6. 日誌只有新條目淡入；沒有重要條目（突破、奇遇）的強調。
7. 數字（修為、靈石、壽元）直接替換，沒有滾動。

**缺的操作性**（`src/ui` 內只有 5 處 `:hover`／`:active`／觸控處理，都在地圖與基礎按鈕）
1. 沒有 `:active` 按壓回饋，手機點了沒有立刻反應。
2. 沒有手勢：不能滑動切換「修行／煉製／行囊／角色」分頁，日誌不能點開詳情，事件不能下拉關閉。
3. 沒有觸覺回饋（`navigator.vibrate`）。
4. 日常安排只能點擊切換，沒有長按說明。
5. （更正）手機寬度本來就有固定在底部的分頁列（`responsive.css`），只是分頁只能點，不能滑動。

**階段 1 已做（分支 ai/claude-m48）**：動畫 token（`--dur-press`、`--press-scale`、`--stagger`）；按鈕 `:active` 縮放與 `touch-action: manipulation`；事件選項依序進場（只限事件視窗）；`src/ui/gesture.ts`（`swipeOf`、`onSwipe`、`neighbourOf`，只認觸控與手寫筆）；手機左右滑動切換側欄分頁（略過鎖住的分頁，到頭不循環）；`src/ui/haptics.ts`（`navigator.vibrate`，更多選單可關，偏好存 localStorage `xiuxian-haptics`）。尚未做：長按說明（安排卡片本來就直接顯示說明，建議略過）、日誌點開詳情。

**階段 2 已做（修行主畫面，同分支）**：`src/ui/tween.ts` 數字滾動（靈石與修為順著進度條爬升，換階段或歸零不滾動，背景頁與減少動態直接跳）；一年十二格月份刻度（`#yearPips`，目前月亮起）；修為圓滿且可突破時進度條邊框呼吸（`.progress.ready`）；新出現的「偶得」「後續」日誌條目多一次底色閃動。

**階段 2 續（同分支）**：外出歷練場景改為趕路（拄杖、身形起伏、遠近山不同速度後移，隱藏打坐光圈與靈氣）；事件選項選中後亮起、其餘淡出，停 170 毫秒再結算（減少動態時直接結算）；遇怪打擊感（怪受創 → 怪圖震動閃白，自己受創 → 整張卡震動閃紅框，傷害 ≥ 30% 震幅加倍，並帶觸覺回饋）；`flash` 改為只認自身的 `animationend`。尚未盤點：天劫視窗、擲骰、天下圖、行囊、回顧、收藏。

**階段 3（同分支）：天劫、擲骰、行囊、一生回顧、收藏**
- 天劫：每道劫雷落下整張卡亮一下並微震、過關閃重點色邊框並帶觸覺；光圈靶圈在判定視窗（一輪的 50%–82%）內變實線加亮；按下後靶圈脹開（凝神）或光圈晃動（失敗）。**順手修正既有 bug**：判定計時每道重置、但光圈 CSS 動畫不重啟，第 2 道起畫面與判定視窗會錯位，現在每道都重啟動畫。
- 擲骰：換命盤（開局、重擲、擇身、新的一世）時各區塊依序進場，四個屬性從 0 依序滾到點數；改選心法、國數只重畫、不重播。
- 行囊：數量增加或新入手的物品亮重點色框、消耗的閃警示色框。
- 一生回顧：各項依序浮現，道韻數字在該行出現時從 0 滾上去。收藏：同樣依序浮現（最多 8 個延遲，長清單不用久等）。
- 共用：`rollNumber` 可指定起點並先畫起點；`revealIn`；`haptic` 在使用者尚未操作頁面時不震動（避免瀏覽器擋下並報錯）。

**階段 4（同分支）：天下圖**
- 路線與虛線：行進路線朝目的地流動（走路中較快）、國戰推進箭頭朝被攻處流動、世仇線緩緩流動；互惠線維持靜止以便區分。
- 選取回饋：剛選到的標記由大收回，資訊卡由上淡入；**只在選取改變時播**。
- 相位連續：地圖每個季度重建節點，動畫會從頭開始，所以 `keepPhase` 以負延遲接回現在的相位（路線、箭頭、世仇線、你的光圈、高亮圈），虛線不會每三秒跳一次。
- 沒做：開圖時標記逐個浮現（重建頻繁，要另處理）、領土變色的漸變（底圖是 canvas）、時間軸拖動時的過場。

**驗收原則（階段 1 起沿用）**：只動 `src/ui/`；動畫可跳過且遵守 `prefers-reduced-motion`；色碼只進 `tokens.css`；`npm run sim` 輸出必須逐字不變；每個畫面在 375px 與桌面都實測。

**未驗證**：未在真機測觸控；未盤點其他畫面（擲骰、天下圖、行囊、回顧、收藏），待使用者選定修行主畫面之後的順序。
